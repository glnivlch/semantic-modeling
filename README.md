# Тема работы: «Разработка системы семантического моделирования предметной области с динамическими графами знаний и поддержкой взаимодействия на естественном языке»
**Цель работы:** Разработка программной системы для представления предметной области в виде человеко-читаемого семантического графа на основе моделей Жинкина, Новикова и Минского.

- [ ] Выбор технологий и инструментов разработки
